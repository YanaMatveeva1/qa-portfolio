# Матрица трассировки требований (RTM)

**Объект тестирования:** электронный журнал онлайн-школы, раздел «Расписание»
**Окружение:** Windows 11, Google Chrome 151.0.7922.138 (64-bit)

RTM показывает, все ли требования покрыты проверками и какие из них
подтверждены прогоном. Каждое требование связано с тест-кейсом, проверками из
чек-листа и, если проверка провалилась, — с заведённым дефектом.

| REQ-01 | Система отображает расписание выбранного класса или группы | [TC-01](test-cases.md#tc-01) | CL-01 | Пройдено |
| REQ-02 | При выборе дня с занятиями система отображает список уроков: время, название, ответственный преподаватель | [TC-02](test-cases.md#tc-02) | CL-03, CL-06 | Частично — [BUG-02](bug-reports.md#bug-02) |
| REQ-03 | Пользователь может просматривать расписание по месяцам, неделям и дням | [TC-03](test-cases.md#tc-03) | CL-02, CL-04, CL-07, CL-08 | Частично — [BUG-03](bug-reports.md#bug-03) |

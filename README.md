## Содержание

### 1. Электронный журнал онлайн-школы — папка `journal`

Полный комплект тестовой документации на одну функциональность — раздел
«Расписание». Артефакты связаны между собой сквозной трассировкой:
требование → тест-кейс → проверка в чек-листе → дефект.

| Документ | Что внутри |
|---|---|
| [Матрица трассировки (RTM)](journal/journal-rtm.md) | 4 требования, покрытие тестами и проверками |
| [Тест-кейсы](journal/journal-test-cases.md) | 4 подробных кейса с шагами и ожидаемым результатом |
| [Чек-лист](journal/journal-checklist.md) | 8 проверок с результатами прогона |
| [Баг-репорты](journal/journal-bug-reports.md) | 3 дефекта с шагами воспроизведения |

*Название и адрес системы не указаны намеренно: это внутренний учебный портал.
Учётные данные в документации заменены плейсхолдерами.*

### 2. Онлайн-библиотека ЛитМир — папка `litmir`

Функциональное тестирование публичного веб-сайта: регистрация, авторизация,
поиск, работа с книгами и сериями, социальные функции.

| Документ | Что внутри |
|---|---|
| [Тест-кейсы (Markdown)](litmir/litmir-test-cases.md) | 24 кейса: 18 позитивных и 6 негативных |
| [Тест-кейсы (Excel)](litmir/litmir-test-cases.xlsx) | та же таблица для скачивания |

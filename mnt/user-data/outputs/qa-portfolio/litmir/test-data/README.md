# Тестовые данные

Файлы, необходимые для выполнения тест-кейсов:

| Файл | Используется в | Назначение |
|---|---|---|
| `book.fb2` | TC-05 | корректный файл книги для загрузки |
| `cover.jpg` | TC-05 | обложка книги |
| `wrong-format.exe` | TC-23 | файл неподдерживаемого формата для негативной проверки |

Тестовые данные хранятся вместе с документацией намеренно: если они лежат во
внешнем облаке, ссылки со временем перестают работать и тест-кейс становится
невоспроизводимым.

**Учётные записи здесь не хранятся.** Логины и пароли тестовых пользователей
передаются отдельно и в документацию не попадают.

# Тест-кейсы — раздел «Расписание»

**Объект тестирования:** электронный журнал онлайн-школы
**Окружение:** Windows 11, Google Chrome 151.0.7922.138 (64-bit)
**Учётные данные:** реальные логин и пароль в документации не хранятся,
в шагах используются плейсхолдеры

**Общие предусловия для всех кейсов:**
пользователь зарегистрирован в системе и имеет доступ к разделу «Расписание».

---

## TC-01

**Название:** Отображение расписания выбранного класса
**Требование:** REQ-01
**Приоритет:** Высокий
**Статус:** Pass

**Предусловия:** пользователь не авторизован

**Тестовые данные:**
- Логин: `<тестовый логин>`
- Пароль: `<тестовый пароль>`

**Шаги выполнения:**

1. Открыть страницу входа в журнал.
2. В поле «Логин» ввести значение из тестовых данных.
3. В поле «Пароль» ввести значение из тестовых данных.
4. Нажать кнопку «Вход».
5. В левом меню выбрать раздел «Расписание».

**Ожидаемый результат:** открывается раздел «Расписание», отображается
календарь текущего месяца с расписанием класса пользователя.

---

## TC-02

**Название:** Просмотр информации об уроке в дне с занятиями
**Требование:** REQ-02
**Приоритет:** Высокий
**Статус:** Pass

**Предусловия:** выполнены шаги 1–5 из TC-01, открыт раздел «Расписание»

**Тестовые данные:** день с запланированными занятиями — 5 сентября

**Шаги выполнения:**

1. Нажать стрелку «>» рядом с названием текущего месяца, чтобы перейти
   к сентябрю.
2. Нажать на день «5» в календаре.

**Ожидаемый результат:** открывается всплывающее окно с информацией об уроке:
дата, время начала и окончания, название предмета, ответственный
преподаватель.

---

## TC-03

**Название:** Переключение периодов просмотра расписания
**Требование:** REQ-03
**Приоритет:** Средний
**Статус:** Fail — см. [BUG-03](bug-reports.md#bug-03)

**Предусловия:** выполнены шаги 1–5 из TC-01, открыт раздел «Расписание»

**Шаги выполнения:**

1. Переключить вид расписания на «Месяц».
2. Убедиться, что отображается сетка календаря за месяц.
3. Переключить вид расписания на «Неделя».
4. Убедиться, что отображаются дни текущей недели.
5. Переключить вид расписания на «День».
6. Нажать на дату текущего дня, чтобы выбрать другую дату.

**Ожидаемый результат:** во всех трёх режимах расписание отображается
корректно; в режиме «День» при нажатии на дату открывается календарь выбора
другой даты.

**Фактический результат:** шаги 1–5 выполняются корректно. На шаге 6 календарь
выбора даты не открывается.

## TC-04

**Название:** Просмотр дня без занятий
**Требование:** REQ-04
**Приоритет:** Средний
**Статус:** Fail — см. [BUG-01](bug-reports.md#bug-01)

**Предусловия:** выполнены шаги 1–5 из TC-01, открыт раздел «Расписание»

**Тестовые данные:** день без запланированных занятий — 3 сентября

**Шаги выполнения:**

1. Нажать стрелку «>» рядом с названием текущего месяца, чтобы перейти
   к сентябрю.
2. Нажать на день «3» в календаре.

**Ожидаемый результат:** открывается всплывающее окно с сообщением об
отсутствии занятий в выбранный день.

**Фактический результат:** при нажатии на день не происходит ничего:
всплывающее окно не появляется, состояние страницы не меняется.
